# GA4 Playground

Mini e-commerce em React + TypeScript para praticar instrumentação com GA4.

## Rodar

```bash
npm install
npm run dev
```

A aplicação não possui integração com GA4. A ideia é adicionar a camada de Analytics durante o estudo.

Fluxo:
Home -> Produtos -> Produto -> Carrinho -> Checkout -> Compra concluída
